Quest HUD

A Claude Code mod that draws your session as a small game: HP and MP bars for the weekly limit and the context window, and the skill and tasks you are on.

This page runs the mod's real drawing code on an invented session. Nothing is sent anywhere, no model is called, and nothing here reads your machine or GitHub.

            How to switch to it
            
    
              
  1. In Claude Code, run /quest-hud:statusline. It prints this command with your plugin's folder filled in. Run it:
                
    cp "<plugin folder>/scripts/hud-line.sh" ~/.claude/hud-line.sh
    
              
    2. 
              
  2. Add the setting to ~/.claude/settings.json:
                
    "statusLine": { "type": "command", "command": "~/.claude/hud-line.sh" }
    
              
    3. 
              
  3. The 5-hour window shows on its own once it runs low: under 40% left, or less than HP. To show it always, and the cost as well, end the command with --all:
                
    "command": "~/.claude/hud-line.sh --all"
    
                The script can't read the Bars setting. On this page, Bars all stands for this flag.
              
    4. 
              
  4. To show only this line, hide the mod's own: run /plugin configure quest-hud@quest-hud, set Detail to off, then run /reload-plugins.
    5. 
            

            
An update can't reach your copy, and an older copy silently ignores --all. To update it, copy the script again.

            
It needs jq. HP appears only on a Pro, Max or Ultra subscription. Where the mod can't run, copy the script from the repository, as the README says.
