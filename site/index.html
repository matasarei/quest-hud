Quest HUD

A Claude Code mod that draws your session as a small game: HP and MP bars for the weekly limit and the context window, and the skill and tasks you are on.

This page runs the mod's real drawing code on an invented session. Nothing is sent anywhere, no model is called, and nothing here reads your machine or GitHub.

Source and README on GitHub

Without mods

      

      
The classic status line, for sessions where mods do not run. It follows the HP and MP sliders, and no setting changes it. /quest-hud:statusline sets it up.

    


    

      
Commands

      

      
Answers appear in the terminal. The level and the Quest Board show invented examples: this page reads nothing from your machine or GitHub.
